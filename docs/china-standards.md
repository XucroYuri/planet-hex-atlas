# 中国标准核查与整改记录

本文件记录“寰宇图志”（英文名 Orbis Atlas）在**地图区划、行政归属与规范命名**以及**中国经济数据基准**方面对照中国官方标准的现状。审计可重复执行：

```sh
PYTHONPATH=. uv run python pipeline/china_source_audit.py --json > /tmp/china-audit.json
PYTHONPATH=. uv run python tests/china_source_audit_test.py
```

## 当前结论（2026-11-27）

**本站地图尚未达到中国标准地图的合规发布条件。** 具体原因：

1. 底图与国界几何来自 Natural Earth 1:10m ADM0 数据，不是经自然资源主管部门审核的标准地图。
2. 本站为交互式派生地图，未取得审图号。按《地图管理条例》及自然资源部说明，公开的世界地图、历史地图等应依法送审；修改标准地图后再次公开也需重新送审。
3. 以 Natural Earth 数据核查：台湾本岛、香港九龙、澳门半岛样点分别命中独立区域 `TWN`、`HKG`、`MAC`，黄岩岛命中独立区域 `SCR`；东沙岛、太平岛、曾母暗沙附近、钓鱼岛附近样点在轮廓与三档 H3 格网中均无命中。岛礁符号与范围线未按权威图幅核对。
4. 年度 GDP 序列当前来自世界银行 WDI（当年美元口径），与中国国家统计局的人民币、初步核算/修订/最终核实口径不同。现已并列接入国家统计局公告，但未替换全部年份。

因此，本站**不得**被描述为“符合中国标准地图”或“官方地图”。在取得审图号、或获授权使用已审核的标准地图几何之前，本站只作为公开数据的科学可视化。

## 已完成的规范对齐

- 中文名称统一为：中国、台湾省、香港特别行政区、澳门特别行政区、黄岩岛。
- 数据层写入行政层级元数据：`TWN` 为 `province`，`HKG`、`MAC` 为 `sar`，`SCR` 为 `reef`，四者的 `sovereignId` 均为 `CHN`；`CHN` 为 `country`。
- 中国档案只把世界银行序列标注为“世界银行”，另以国家统计局公告作为中国官方经济基准，并注明其统计范围不含香港、澳门特别行政区和台湾省的地区生产总值。
- 缺失数据保持为空：台湾省没有可单独匹配的世界银行年度序列时显示缺失，不用其他来源补齐；界面上明确标注缺少来源。
- 应用内“标准与声明”页公开上述状态，并提供自然资源部标准地图服务与审计脚本入口。

## 达到合规发布所需的下一步

按优先级排列，每项都要有可核验产物：

1. **取得标准地图或其授权**：从[自然资源部标准地图服务](http://bzdt.ch.mnr.gov.cn/)取得适用的世界地图标准图幅及审图号；如使用服务提供的世界地图数据，须核实其授权文本是否允许交互式派生，并保留取得时间与文件校验值。
2. **必要时送审**：若对标准地图进行编辑后公开，按“谁公开、谁送审”原则向自然资源主管部门送审，保存受理与审图号记录。
3. **替换几何并逐项对照**：将国界、台湾省、香港、澳门、南海诸岛及附属岛屿、钓鱼岛及其附属岛屿、藏南和阿克赛钦等要素替换为审核图幅的几何或符号，逐幅对照海岸线、岛礁点位和范围线。审计脚本中的 `PROBES` 与阻断项应全部清零。
4. **命名与区划全量核对**：省、自治区、直辖市、特别行政区、台湾省的规范名称和层级由官方名录驱动，不再依赖第三方译名。
5. **统计口径治理**：中国档案以国家统计局为准；与其他国家比较时明确标注世界银行口径，禁止把两个口径相加或混排；逐年接入官方序列并保留修订记录。
6. **复核**：`pipeline/china_source_audit.py --strict` 无阻断项，且人工对照审图号图幅确认后，方可把发布声明从“科学可视化”改为“已审图”。
