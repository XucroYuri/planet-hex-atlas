# 标准地图送审路径与材料清单

本目录记录“寰宇图志”从当前科学可视化地图走向可公开使用的标准地图所需的行政路径。它不是审图结论，也不代表已经具备送审资格；用途是把下一步工作具体化。

## 法律与受理依据

- [《地图管理条例》](https://xzfg.moj.gov.cn/front/law/detail?LawID=421)（2015 年 11 月 26 日国务院令第 664 号，2016 年 1 月 1 日施行）：
  - 第七条：从事地图编制活动的单位应取得相应测绘资质，并在资质等级许可范围内编制；
  - 第九、十条：世界地图、全国地图应完整表示中国疆域；国界按中国国界线画法标准样图绘制，世界各国间边界按参考样图绘制；
  - 第十六条：向社会公开的地图应送审，材料为**地图审核申请表、地图样图或样品、地图编制单位测绘资质证书**；使用涉密测绘成果的另附保密技术处理证明；
  - 第十七条：**世界地图、全国地图、港澳台地图、历史地图由国务院测绘地理信息主管部门审核**；
  - 第十九条：受理后 20 个工作日内作出决定；第二十一、二十二条：批准后核发审图号并在图上显著标注；
  - 第四十九条：应送审而未送审的，责令改正、警告、没收地图，可处 10 万元以下罚款。
- [自然资源部地图审核政务服务事项材料清单](https://gjzwfw.www.gov.cn/fwmh/item/v3/item_1110000000001360281000105011000.do)：申请表 1 份、最终样图或样品 2 份、测绘资质证书 1 份，保密处理证明为非必要项；不收费，承诺 20 个工作日。

## 材料清单与当前状态

| 材料 | 要求 | 当前状态 | 需谁提供 |
| --- | --- | --- | --- |
| 地图审核申请表 | 自然资源部制式表格，申请人填写地图名称、类型、范围、用途、编制单位等 | 未填写 | 送审主体（持资质编制单位或与其合作的主体） |
| 地图样图或样品 2 份 | 最终公开形态的完整地图，含图名、比例尺、投影、图例、审图号位置 | 未制作；当前底图为 Natural Earth，不是标准样图 | 有测绘资质的编制单位 |
| 测绘资质证书 | 地图编制单位资质，等级与范围覆盖所编地图 | 本项目无测绘资质 | 合作编制单位 |
| 保密技术处理证明 | 仅使用涉密测绘成果时需要 | 不适用（当前使用公开数据） | — |

因此当前**不具备送审主体资格**，不能自行提交；需要与具备测绘资质的单位合作，或由该单位作为编制/送审主体。

## 送审前的工程检查清单

1. **几何替换**：以中国国界线画法标准样图和世界各国国界线画法参考样图为来源，替换 Natural Earth 的国界与区域轮廓；完整表示中国疆域与南海诸岛、台湾岛、钓鱼岛及其附属岛屿等。
2. **导入核验**：对候选几何运行 `uv run pipeline/standard_map_intake.py --geojson ... --approval-number ... --source-url ...`，检查审图号格式、WGS84 经纬度范围、中国/台湾省/香港/澳门要素与九个样点落位；报告只能作为内部检查。
3. **地图要素**：核对比例尺、投影、图名、图例、境界线符号、地名（使用官方标准地名）、重要地理信息数据；确认没有不得表示的内容。
4. **样图制作**：输出最终公开形态的静态样图 2 份，图上预留审图号显著位置；交互页面注明“审图号：待核发/核发后填写”。
5. **数据来源说明**：整理各图层来源、版本、许可与获取日期；本仓库 `web/data/source-lock.json`、`web/data/ATTRIBUTION.txt` 与各管线脚本可作为底稿。
6. **送审与标注**：由持资质单位向国务院测绘地理信息主管部门提交；批准后在网页地图适当位置标注审图号，并按要求送交样本。

## 交接材料包

```bash
uv run python pipeline/build_submission_package.py
```

生成 `dist/standard-map-submission.zip`（不提交到 Git）：包含 `audit.json`、核查状态摘要、来源哈希清单、署名文件、申请字段与法律法规说明。包内**不含**标准地图几何与审图号；适用于移交给具备测绘资质的合作方，避免私下传输未授权图幅。CI 运行 `tests/submission_package_test.py` 校验包内容与“未取得审图号”声明。

## 本机对照工具

网页「标准与声明」页提供“标准地图对照（仅本机）”：用户可在本地选择已下载的标准地图图片、填写审图号并预览，图片不会上传或保存。它用于人工比对，不改变几何、不构成审图结论。

## 与当前应用的关系

- 应用内“标准与声明”页已声明“科学可视化，不是经审核的标准地图”，并给出标准地图服务入口；
- 在取得审图号并完成几何替换前，应用不会声称符合标准地图要求，也不会使用任何审图号占位符；
- 送审路径与材料要求记录在此，随法规或材料清单更新而更新。
