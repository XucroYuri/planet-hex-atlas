# 地图审核申请表填写底稿

这是为与持测绘资质单位合作送审而准备的字段底稿，不是自然资源部制式申请表，也不能替代正式表格。提交前由送审主体按官方表格重新誊写。

## 地图基本信息

- 地图名称：寰宇图志交互地图（送审名称待定）
- 地图类型：世界地图 / 互联网地图（展示、登载）
- 主要表现地：全球；重点表现中华人民共和国全部疆域
- 比例尺：交互多尺度（全球概览至市级），样图标注固定比例尺
- 投影：正射球面与等距圆柱展图（送审样图需固定一种投影并标注）
- 用途：公益性的地理、历史与太空数据可视化展示
- 公开渠道：网站 `earth.xuyu.net`、`planet-hex-atlas.pages.dev`
- 地图幅面：交互页面与静态样图（对开/打印尺寸待定）

## 编制与送审主体

- 地图编制单位：待填写（须持有相应测绘资质）
- 测绘资质证书编号：待填写
- 送审主体：待填写
- 联系人及联系方式：待填写

## 数据与边界来源

- 国界与区域轮廓：待替换为中国国界线画法标准样图 / 世界各国国界线画法参考样图
- 行政区域：按国务院民政部门与测绘地理信息主管部门公布的行政区域界线标准画法图
- 地形与高程：GMT / SRTM15+ 等公开数据（详见 `web/data/ATTRIBUTION.txt`）
- 人口、经济、社会指标：世界银行 WDI、联合国、Our World in Data 等公开来源，逐项见应用“数据来源与方法”
- 中国官方经济数据：国家统计局《中国统计年鉴 2024》与年度公告，见 `docs/china-standards.md`

## 送审前确认项

- [ ] 中国疆域完整表示（含台湾岛、南海诸岛、钓鱼岛及其附属岛屿等）
- [ ] 国界、世界国界按标准样图/参考样图绘制
- [ ] 行政区域界线、名称符合规定
- [ ] 重要地理信息数据使用依法公布的数据
- [ ] 地名使用标准地名
- [ ] 无不得表示的内容
- [ ] 静态样图 2 份，审图号位置显著
- [ ] 资质证书与申请表齐全
- [ ] 批准后在网页与样图标注审图号
